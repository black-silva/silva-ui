# Props reference

This is the practical prop reference. Component-specific props are listed below, while the shared styling props work on every primitive unless the component calls out an exception.

## Shared props on every component

All primitives accept these props in addition to the props in their own row. They are forwarded with the remaining valid HTML attributes, including relevant event handlers such as `onClick`, `onChange`, `onInput`, `onFocus`, `onBlur`, `onKeyDown`, and ARIA/data attributes.

| Prop group | Props you can use | What it does |
| --- | --- | --- |
| Content and escape hatches | `children`, `class` | Render nested content; append CSS classes after generated styles. |
| Colour and visual treatment | `color`, `backgroundColor`, `borderColor`, `borderWidth`, `borderStyle`, `borderRadius`, `opacity`, `animation` | Use theme colour tokens; `color` and `backgroundColor` also accept named gradients. |
| Layout | `display`, `flexDirection`, `alignItems`, `justifyContent`, `flexWrap`, `flexGrow`, `flexShrink`, `alignSelf`, `gap` | Build flex and grid arrangements without application CSS. |
| Spacing | `p`, `px`, `py`, `pt`, `pr`, `pb`, `pl`, `m`, `mx`, `my`, `mt`, `mr`, `mb`, `ml` | Padding and margin aliases; long forms such as `paddingTop` also work. |
| Sizing | `w`, `h`, `width`, `height`, `minWidth`, `minHeight`, `maxWidth`, `maxHeight` | Token sizes and fluid projection values such as `$4`. |
| Type | `fontSize`, `fontWeight`, `lineHeight`, `textAlign`, `textDecoration`, `textTransform`, `letterSpacing`, `whiteSpace`, `wordBreak` | Token-driven text presentation. |
| Position and overflow | `position`, `top`, `right`, `bottom`, `left`, `zIndex`, `overflow`, `overflowX`, `overflowY`, `visibility` | Position surfaces and control clipped content. |
| Interaction and media | `cursor`, `pointerEvents`, `userSelect`, `objectFit` | Interaction affordances and image fitting. |

`ComponentSize` means `xs | sm | md | lg | xl`. Projection-capable spacing, sizing, `fontSize`, `borderRadius`, and position props accept a fluid `$n` token as well as regular token values.

## Layout

| Component | Component props | Common / native props |
| --- | --- | --- |
| `Box` | `as?: string`; `gradient?: Gradient` | Shared props, especially layout, spacing, sizing, colours, `class`, and `children`; native props for the chosen element. |
| `XStack` | No component-specific props | Shared flex, gap, spacing, sizing, colours, `class`, and `children`; normal container attributes. |
| `YStack` | No component-specific props | Shared flex, gap, spacing, sizing, colours, `class`, and `children`; normal container attributes. |
| `XGroup` | No component-specific props | Shared layout and spacing props; `class`, `children`, and normal container attributes. |
| `Separator` | `orientation?: "horizontal" | "vertical"`; `decorative?: boolean` (default `true`) | Shared size, colour, margin, and `class`; use `decorative={false}` to expose separator semantics. |

## Typography

| Component | Component props | Common / native props |
| --- | --- | --- |
| `Text` | `as?: string` | Shared type, colour, spacing, sizing, layout, `class`, `children`; attributes for the rendered element. |
| `SizableText` | `size?: ComponentSize` | `Text` shared props plus `size`; `class`, `children`, and native text-element attributes. |
| `Paragraph` | `size?: ComponentSize` (defaults to `md`) | Shared type, colour, spacing, sizing, `class`, `children`; native paragraph attributes. |
| `Heading` | `level?: 1 | 2 | 3 | 4 | 5 | 6` | Shared type, colour, spacing, sizing, `class`, `children`; native heading attributes. |
| `H1` through `H6` | Fixed semantic heading level | The same shared props as `Heading`, including `fontSize`, `color`, spacing, `class`, and `children`. |
| `Anchor` | `href?: string`; `target?: string`; `rel?: string`; `disabled?: boolean` | Shared type, colour, spacing, `class`, `children`; native link attributes and events. `_blank` gets `noopener noreferrer` when `rel` is absent. |

## Forms and input

| Component | Component props | Common / native props |
| --- | --- | --- |
| `Button` | `type?: "button" | "submit" | "reset"`; `variant?: "solid" | "outline" | "ghost" | "link"`; `size?: ComponentSize`; `disabled?: boolean` | Shared colour, spacing, layout, `class`, `children`; button attributes and events including `onClick`, `onFocus`, and `onBlur`. |
| `Input` | `size?: ComponentSize` | Shared styling props and normal input attributes: `type`, `name`, `id`, `value`, `defaultValue`, `placeholder`, `disabled`, `required`, `readOnly`, `min`, `max`, `step`, `onInput`, `onChange`. |
| `TextArea` | `size?: ComponentSize` | Shared styling props and textarea attributes: `name`, `id`, `value`, `defaultValue`, `placeholder`, `rows`, `cols`, `disabled`, `required`, `readOnly`, `onInput`, `onChange`. |
| `Label` | `htmlFor?: string`; `size?: ComponentSize`; `required?: boolean` | Shared type, colour, spacing, `class`, `children`; label attributes and events. |
| `Form` | No component-specific props | Shared layout, spacing, colour, `class`, `children`; form attributes such as `action`, `method`, `noValidate`, and `onSubmit`. |
| `Field` | `error?: string`; `helperText?: string` | Shared layout, spacing, colour, `class`, `children`; container attributes. |
| `FieldError` | No component-specific props | Shared type, colour, spacing, `class`, `children`; container attributes. |
| `FieldHelper` | No component-specific props | Shared type, colour, spacing, `class`, `children`; container attributes. |
| `Checkbox` | `label?: string`; `size?: ComponentSize` | Shared styling props plus checkbox attributes: `checked`, `defaultChecked`, `disabled`, `name`, `value`, `id`, `required`, `onChange`. |
| `RadioGroup` | `name?: string`; `value?: string`; `defaultValue?: string` | Shared layout, gap, spacing, `class`, `children`; group attributes and events. Application state controls which item is checked. |
| `RadioGroupItem` | `value: string` **required**; `name?: string`; `size?: ComponentSize` | Shared styling props plus radio attributes: `checked`, `defaultChecked`, `disabled`, `id`, `required`, `onChange`. |
| `Select` | `size?: ComponentSize` | Shared styling props plus select attributes: `name`, `id`, `value`, `defaultValue`, `disabled`, `required`, `multiple`, `onChange`, and option `children`. |
| `Slider` | `size?: ComponentSize` | Shared styling props plus range attributes: `min`, `max`, `step`, `value`, `defaultValue`, `disabled`, `name`, `id`, `onInput`, `onChange`. |
| `Switch` | `size?: ComponentSize` | Shared styling props plus checkbox-like attributes: `checked`, `defaultChecked`, `disabled`, `name`, `value`, `id`, `required`, `onChange`. |
| `ToggleGroup` | `type?: "single" | "multiple"` | Shared layout, gap, spacing, `class`, `children`; container attributes. Your app owns active-state coordination. |
| `ToggleGroupItem` | `value: string` **required**; `data-active?: boolean | string`; `disabled?: boolean` | Shared styling props, `class`, `children`, and button events such as `onClick`. |
| `Progress` | `value?: number`; `max?: number`; `size?: ComponentSize` | Shared size, colour, spacing, `class`; progress attributes including `aria-label` and `aria-valuetext`. |

## Overlays and compound elements

These are visual primitives. Your application owns portals, focus trapping, Escape handling, positioning, and state coordination. Pass `data-state="open" | "closed"` to the parts that animate or hide.

| Component | Component props | Common / native props |
| --- | --- | --- |
| `Tabs` | `value?: string` | Shared layout, spacing, `class`, `children`; your state selects the active tab. |
| `TabList` | `aria-label?: string` | Shared layout, gap, spacing, `class`, `children`; tablist ARIA attributes. |
| `Tab` | `value?: string`; `data-active?: boolean | string`; `aria-controls?: string`; `aria-selected?: boolean`; `id?: string` | Shared styling, `class`, `children`; button attributes and `onClick`. |
| `TabPanel` | `value?: string`; `hidden?: boolean`; `id?: string`; `aria-labelledby?: string` | Shared layout, spacing, `class`, `children`; region attributes. |
| `Dialog` | `open?: boolean` | Shared `class` and `children`; the root exposes `data-state`. |
| `DialogOverlay` | `data-state?: "open" | "closed"` | Shared background colour, opacity, position, `class`; overlay click and ARIA attributes. |
| `DialogContent` | `data-state?: "open" | "closed"` | Shared layout, size, spacing, background colour, `class`, `children`; dialog ARIA attributes. |
| `DialogHeader`, `DialogFooter`, `DialogTitle`, `DialogDescription`, `DialogClose` | No component-specific props | Shared layout/type/spacing/colour props, `class`, `children`; `DialogClose` also accepts button events. |
| `AlertDialog` | `open?: boolean` | Shared `class` and `children`; the root exposes `data-state`. |
| `AlertDialogOverlay`, `AlertDialogContent` | `data-state?: "open" | "closed"` | Same shared overlay/content styling props as `Dialog`; content has alert-dialog ARIA semantics. |
| `AlertDialogHeader`, `AlertDialogFooter`, `AlertDialogTitle`, `AlertDialogDescription` | No component-specific props | Shared layout/type/spacing/colour props, `class`, `children`. |
| `AlertDialogAction`, `AlertDialogCancel` | No component-specific props | Shared styling, `class`, `children`; button attributes and `onClick`. |
| `Popover` | No component-specific props | Shared `class`, `children`; your application owns open state. |
| `PopoverTrigger`, `PopoverClose` | No component-specific props | Shared styling, `class`, `children`; button attributes and events. |
| `PopoverContent` | `side?: "top" | "bottom" | "left" | "right"`; `data-state?: "open" | "closed"` | Shared layout, spacing, background colour, position, `class`, `children`. |
| `Sheet` | `open?: boolean` | Shared `class` and `children`; the root exposes `data-state`. |
| `SheetOverlay` | `data-state?: "open" | "closed"` | Shared overlay styling, `class`, and events. |
| `SheetContent` | `side?: "top" | "bottom" | "left" | "right"`; `data-state?: "open" | "closed"` | Shared layout, size, spacing, background colour, `class`, `children`; dialog ARIA attributes. |
| `SheetHeader`, `SheetFooter`, `SheetTitle`, `SheetDescription` | No component-specific props | Shared layout/type/spacing/colour props, `class`, `children`. |
| `SheetClose` | No component-specific props | Shared styling, `class`, `children`; button attributes and `onClick`. |
| `Tooltip`, `TooltipTrigger` | No component-specific props | Shared `class`, `children`; trigger events such as `onMouseEnter`, `onMouseLeave`, `onFocus`, and `onBlur`. |
| `TooltipContent` | `side?: "top" | "bottom" | "left" | "right"`; `data-state?: "open" | "closed"` | Shared colour, spacing, position, `class`, `children`. |
| `ToastProvider` | `position?: "top-right" | "top-left" | "bottom-right" | "bottom-left" | "top-center" | "bottom-center"` | Shared spacing, `class`, `children`; it is a fixed toast viewport. |
| `Toast` | `variant?: "default" | "success" | "error" | "warning"` | Shared layout, spacing, background colour, `class`, `children`; role is `status` with polite live announcements. |
| `ToastTitle`, `ToastDescription` | No component-specific props | Shared type, colour, spacing, `class`, `children`. |
| `ToastClose` | No component-specific props | Shared styling, `class`, `children`; button attributes and `onClick`. |
| `Menu` / `ContextMenu` | No component-specific props | Shared `class`, `children`; your app owns the open state and placement. |
| `MenuTrigger` / `ContextMenuTrigger` | No component-specific props | Shared styling, `class`, `children`; trigger events such as `onClick` or `onContextMenu`. |
| `MenuContent` / `ContextMenuContent` | `data-state?: "open" | "closed"` | Shared layout, spacing, background colour, position, `class`, `children`. |
