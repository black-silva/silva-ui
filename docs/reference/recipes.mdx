# Recipes

## Settings row

Use layout primitives and a `Switch` to create a compact, readable preference row.

<Tabs sync={false}>
  <Tab title="Code">

```tsx
<XStack p="medium" alignItems="center" justifyContent="space-between" bg="card" borderRadius="medium">
  <YStack gap="xs">
    <Text fontWeight="medium">Email notifications</Text>
    <Text fontSize="sm" color="muted">Receive a summary of account activity.</Text>
  </YStack>
  <Switch name="email-notifications" defaultChecked />
</XStack>
```

## Controlled toast region

<Tabs sync={false}>
  <Tab title="Code">

```tsx
<ToastProvider position="top-right">
  {saved && (
    <Toast variant="success">
      <ToastTitle>Changes saved</ToastTitle>
      <ToastDescription>Your profile is up to date.</ToastDescription>
      <ToastClose onClick={() => setSaved(false)}>Close</ToastClose>
    </Toast>
  )}
</ToastProvider>
```
