# Build Hono UIs with composable primitives

**silva-ui** ships prebuilt Vanilla Extract CSS, typed sprinkles, theme scopes, and composable Hono JSX primitives. Pick an API below to see its preview, props, and implementation patterns.

<Note>
Import the stylesheet once with `import "silva-ui/style.css"`. The package has a peer dependency on `hono@^4.13.13`.
</Note>
