# Loader

A linear indeterminate loading indicator.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { Loader } from "silva-ui"

<Loader aria-label="Saving changes" />
```

## Another composition

```tsx
import { Loader } from "silva-ui"

<Loader size="sm" color="primary" />
```

| Prop | Type / behaviour |
