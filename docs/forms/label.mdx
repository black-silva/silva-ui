# Label

A semantic label primitive for form controls.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Preview

<Frame>

## Basic usage

```tsx
import { Label } from "silva-ui"

<Label for="email">Email address</Label>
```

## Another composition

```tsx
import { Label } from "silva-ui"

<Label color="muted" fontSize="sm">Optional</Label>
```

## Props

| Prop | Type / behaviour |
| --- | --- |
| API-specific props | for: `string`; disabled: `boolean` |
