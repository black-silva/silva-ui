# Select

A styled select control with native option markup.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { Select } from "silva-ui"

<Select name="plan" defaultValue="starter"><option value="starter">Starter</option><option value="pro">Pro</option></Select>
```

## Another composition

```tsx
import { Select } from "silva-ui"

<Select aria-label="Visibility"><option>Private</option><option>Public</option></Select>
```
