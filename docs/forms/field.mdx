# Field

A field wrapper that shows help text or an error below a control. Errors take priority.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { Field, FieldError, FieldHelper } from "silva-ui"

<Field helperText="We will never share it."><Label for="email">Email</Label><Input id="email" /></Field>
```

## Another composition

```tsx
import { Field } from "silva-ui"

<Field error="Enter a valid email address."><Input aria-invalid="true" /></Field>
```
