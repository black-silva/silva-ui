# Checkbox

A native checkbox with Silva UI styling.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { Checkbox } from "silva-ui"

<Checkbox id="terms" name="terms" required />
```

## Another composition

```tsx
import { Checkbox } from "silva-ui"

<Checkbox defaultChecked aria-label="Enable email alerts" />
```
