# Button

A styled action control for application actions.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

| Prop | Type / behaviour |
| --- | --- |
| API-specific props | type: `button` \| `submit` \| `reset` (default `button`); variant: `solid` \| `outline` \| `ghost` \| `link`; disabled: `boolean`; size: `ComponentSize`; onClick: event handler |
