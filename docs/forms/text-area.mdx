# TextArea

A token-aware multi-line input that forwards native textarea attributes.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { TextArea } from "silva-ui"

<TextArea name="message" rows={5} placeholder="Tell us what you need." />
```

## Another composition

```tsx
import { TextArea } from "silva-ui"

<TextArea size="lg" defaultValue="Draft message" />
```

| Prop | Type / behaviour |
