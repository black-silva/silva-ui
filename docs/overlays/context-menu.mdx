# ContextMenu

A menu family for context actions. Your app attaches the context-menu event and controls visibility.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { ContextMenu, ContextMenuTrigger, ContextMenuContent, ContextMenuItem, ContextMenuSeparator, ContextMenuLabel, ContextMenuGroup } from "silva-ui"

<ContextMenu><ContextMenuTrigger>Right-click target</ContextMenuTrigger><ContextMenuContent data-state="open"><ContextMenuItem>Rename</ContextMenuItem></ContextMenuContent></ContextMenu>
```

## Another composition

```tsx
import { ContextMenu } from "silva-ui"

<ContextMenuItem disabled>Delete</ContextMenuItem>
```
