# ContextMenu

Two rendered compositions using exported Silva UI components. The code beside each preview is the implementation rendered by that preview. Components that need application state use an explicit static state here.

```tsx
<ContextMenu>
  <ContextMenuTrigger>
    <Button variant="outline">Right-click for actions</Button>
  </ContextMenuTrigger>
  <ContextMenuContent data-state="closed">
    <ContextMenuLabel>Actions</ContextMenuLabel>
    <ContextMenuGroup><ContextMenuItem>Edit</ContextMenuItem></ContextMenuGroup>
    <ContextMenuSeparator />
    <ContextMenuItem>Delete</ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>
```
