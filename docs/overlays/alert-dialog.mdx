# AlertDialog

A destructive-action dialog. AlertDialogContent renders `role="alertdialog"`.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { AlertDialog, AlertDialogOverlay, AlertDialogContent, AlertDialogHeader, AlertDialogFooter, AlertDialogTitle, AlertDialogDescription, AlertDialogAction, AlertDialogCancel } from "silva-ui"

<AlertDialog open><AlertDialogContent><AlertDialogTitle>Delete project?</AlertDialogTitle><AlertDialogAction>Delete</AlertDialogAction></AlertDialogContent></AlertDialog>
```

## Another composition

```tsx
import { AlertDialog } from "silva-ui"

<AlertDialogContent data-state="open">Important confirmation</AlertDialogContent>
```
