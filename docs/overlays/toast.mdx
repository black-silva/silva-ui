# Toast

A static toast composition. Queueing, timeouts, and dismissal belong to the application.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Props

| Prop | Type / behaviour |
| --- | --- |
| API-specific props | ToastProvider.position: six screen positions; Toast.variant: `default` | `success` | `error` | `warning`; title/description/close: `BaseProps` |

For the complete public contract, see [Props reference](/docs/reference/props).
