# Toast

Two rendered compositions using exported Silva UI components. The code beside each preview is the implementation rendered by that preview. Components that need application state use an explicit static state here.

```tsx
import { Button, Toast, ToastClose, ToastDescription, ToastProvider, ToastTitle } from "silva-ui"

<Button>Show saved toast</Button>
<ToastProvider position="bottom-center">
  <div hidden>
    <Toast variant="default">
      <ToastTitle>Saved</ToastTitle>
```
