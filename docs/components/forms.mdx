# Forms and controls

Form components render native elements, then layer the Silva visual system on top. Pair labels with matching `id` values for accessible controls.

## Field composition

`Form` is a vertical form wrapper. `Field` groups a control with `error` or `helperText`; its `FieldError` and `FieldHelper` exports are available for custom layouts.

<Tabs sync={false}>
  <Tab title="Code">

```tsx
<Form action="/subscribe" method="post" gap="medium">
  <Field helperText="We will only send product updates.">
    <Label htmlFor="email" required>Email address</Label>
    <Input id="email" name="email" type="email" placeholder="you@example.com" required />
  </Field>
  <Button type="submit">Subscribe</Button>
</Form>
```

## Inputs

`Input`, `TextArea`, `Select`, and `Label` support `sm`, `md` and `lg` sizes. Inputs expose the standard native fields such as `name`, `value`, `defaultValue`, `disabled`, `required`, and `onChange`.

<Tabs sync={false}>
  <Tab title="Code">

```tsx
<Field>
  <Label htmlFor="message">Message</Label>
  <TextArea id="message" rows={5} placeholder="Tell us what you need." />
</Field>
```

## Choice controls

| Component | Key props |
| --- | --- |
| `Checkbox` | `checked`, `defaultChecked`, `disabled`, `name`, `value` |
| `RadioGroup` / `RadioGroupItem` | group `name`; item `value`, `checked`, `defaultChecked` |
| `Switch` | `checked`, `defaultChecked`, `disabled` |
| `ToggleGroup` / `ToggleGroupItem` | group `type="single" | "multiple"`; item `value`, `data-active` |
| `Slider` | `min`, `max`, `step`, `value`, `defaultValue` |
| `Progress` | `value`, `max`, `aria-label` |

<Tabs sync={false}>
  <Tab title="Code">

```tsx
<YStack gap="medium">
  <Checkbox name="terms" value="accepted">I agree to the terms</Checkbox>
  <Switch name="alerts" defaultChecked>Enable alerts</Switch>
  <RadioGroup name="plan" defaultValue="pro">
    <RadioGroupItem value="starter">Starter</RadioGroupItem>
    <RadioGroupItem value="pro">Pro</RadioGroupItem>
  </RadioGroup>
  <Progress value={72} max={100} aria-label="Profile completeness" />
</YStack>
```

## Buttons

`Button` supports `xs` through `xl` sizes and `solid`, `outline`, `ghost`, and `link` variants.

<Tabs sync={false}>
  <Tab title="Code">

```tsx
<XStack gap="small">
  <Button>Save changes</Button>
  <Button variant="outline">Preview</Button>
  <Button variant="ghost">Cancel</Button>
</XStack>
```
