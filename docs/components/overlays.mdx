# Overlays and compound components

These components provide structure, styling, ARIA roles, and state data attributes. They are deliberately **stateless**: your application owns interaction, focus management, keyboard handling, and portal behaviour.

For production modal behaviour, add your own focus trap, Escape handling, background inertness, and portal strategy around the visual primitives.

## Tabs

Tabs are stateless. Keep the selected value in application state, set `data-active` on the current tab, and hide inactive panels.

## Accordion

`Accordion` is stateless. Apply `data-state="open" | "closed"` to each item, trigger, and content from your own state.

<Tabs sync={false}>
  <Tab title="Preview">

<Frame>
  <iframe src="https://black-silva.github.io/silva-ui/previews/?example=overlay-10" title="Rendered Accordion preview" className="w-full h-80 rounded-xl"></iframe>
</Frame>

  </Tab>
  <Tab title="Code">

```tsx
function AccordionPreview() { const [openItem, setOpenItem] = useState(''); return <Accordion type="single"><AccordionItem value="shipping" data-state={openItem === 'shipping' ? 'open' : 'closed'}><AccordionTrigger onClick={() => setOpenItem(openItem === 'shipping' ? '' : 'shipping')} data-state={openItem === 'shipping' ? 'open' : 'closed'}>When does my order ship?</AccordionTrigger><AccordionContent data-state={openItem === 'shipping' ? 'open' : 'closed'}>Orders leave our warehouse in one to two business days.</AccordionContent></AccordionItem></Accordion>; }
```

  </Tab>
</Tabs>
