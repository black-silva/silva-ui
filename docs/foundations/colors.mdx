# Colors

The exported maps behind theme-aware semantic colours.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { colorScales, darkColorScales, colorTokens, darkColorTokens } from "silva-ui"

<Box backgroundColor="primary" color="primaryForeground" p="md">Semantic colour</Box>
```

## Another composition

```tsx
import { colorScales } from "silva-ui"

<Text color="muted">Tokens adapt inside Theme.</Text>
```

## Props

| Prop | Type / behaviour |
| --- | --- |
| API-specific props | colorTokens/darkColorTokens: semantic maps; colorScales/darkColorScales: scales; ColorTokenName: token union |

For the complete public contract, see [Props reference](/docs/reference/props).
