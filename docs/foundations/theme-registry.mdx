# Theme registry

Runtime registry utilities for application-owned theme records.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { addTheme, getTheme, getThemes, replaceTheme, updateTheme } from "silva-ui"

addTheme({ name: "brand", values: { /* semantic values */ } })
```

## Another composition

```tsx
import { addTheme } from "silva-ui"

const active = getTheme("brand")
```

## Props

| Prop | Type / behaviour |
| --- | --- |
| API-specific props | addTheme/replaceTheme/updateTheme use ThemeMutation; getTheme returns a ThemeRecord |

For the complete public contract, see [Props reference](/docs/reference/props).
