# Layout primitives

All layout components accept shared sprinkles props such as `p`, `gap`, `bg`, `borderRadius`, `width` and `alignItems`.

## Box

`Box` is the foundation primitive. It renders a `div` by default and supports `as` for a different element.

```tsx
import { Box, H3, Text, XStack, YStack } from "silva-ui"

const variant = 0;

<Box as="article" p="large" borderRadius="large" width="64" minHeight="48" overflow="hidden" gradient={{ from: 'blue10', via: 'blue9', to: 'teal9', deg: 135 }} color="background"><YStack gap="small"><Text fontSize="xs" fontWeight="bold" letterSpacing="widest">{variant ? 'WORKSPACE' : 'FOUNDATION'}</Text><H3 color="background">{variant ? 'Everything in its place' : 'Build from one good Box'}</H3><Text color="background" fontSize="xs">{variant ? 'projects' : 'tokens'}</Text></YStack><YStack gap="none"><Text color="background" fontSize="lg" fontWeight="bold">{variant ? '4.8' : '100%'}</Text><Text color="background" fontSize="xs" textTransform="uppercase">{variant ? 'rating' : 'composable'}</Text></YStack></XStack></YStack></Box>
```

## Stacks

`YStack` is a vertical flex container and `XStack` is a horizontal flex container.

<Tabs sync={false}>
  <Tab title="Preview">

<Frame>
  <iframe src="https://black-silva.github.io/silva-ui/previews/?example=api-22-a" title="Rendered Silva UI preview" className="w-full h-80 rounded-xl"></iframe>
</Frame>

  </Tab>
  <Tab title="Code">

```tsx
import { Button, Text, XStack, YStack } from "silva-ui"

const variant = 0;

variant ? <XStack gap="small"><Button>Save</Button><Button variant="outline">Cancel</Button></XStack> : <YStack><Text>First</Text><Text>Second</Text></YStack>
```

  </Tab>
</Tabs>

## XGroup

Use `XGroup` for connected horizontal controls. Its children share borders and outer corner radii.

<Tabs sync={false}>
  <Tab title="Preview">

<Frame>
  <iframe src="https://black-silva.github.io/silva-ui/previews/?example=api-23-a" title="Rendered Silva UI preview" className="w-full h-80 rounded-xl"></iframe>
</Frame>

  </Tab>
  <Tab title="Code">

```tsx
import { Button, XGroup } from "silva-ui"

const variant = 0;

<XGroup><Button>{variant ? 'Grid' : 'Day'}</Button><Button>{variant ? 'List' : 'Week'}</Button></XGroup>
```

  </Tab>
</Tabs>

## Separator

`Separator` renders a horizontal rule by default. Set `orientation="vertical"` for an inline divider. Use `decorative` when it is purely visual.

<Tabs sync={false}>
  <Tab title="Preview">

<Frame>
  <iframe src="https://black-silva.github.io/silva-ui/previews/?example=api-21-a" title="Rendered Silva UI preview" className="w-full h-80 rounded-xl"></iframe>
</Frame>

  </Tab>
  <Tab title="Code">

```tsx
import { Separator, Text, YStack } from "silva-ui"

const variant = 0;

<YStack><Text>{variant ? 'Billing' : 'Profile'}</Text><Separator /><Text>{variant ? 'Invoices' : 'Security'}</Text></YStack>
```
