# Sprinkles props

Every component extends `BaseProps`, which includes the generated `Sprinkles` type. The library separates supported styling props from regular HTML attributes, then merges their generated class with any `class` you provide.

## Common properties

| Category | Props |
| --- | --- |
| Spacing | `p`, `px`, `py`, `m`, `mx`, `my`, `gap` |
| Layout | `display`, `flexDirection`, `alignItems`, `justifyContent`, `flexWrap` |
| Size | `width`, `height`, `minWidth`, `maxWidth`, `w`, `h` |
| Colour | `bg`, `backgroundColor`, `color`, `borderColor` |
| Visuals | `animation`; gradients are accepted by `backgroundColor` and `color` |
| Typography | `fontSize`, `fontWeight`, `lineHeight`, `textAlign` |
| Borders | `borderRadius`, `borderWidth`, `borderStyle` |
| Position | `position`, `top`, `right`, `bottom`, `left`, `zIndex` |

## Token values

Spacing uses `none`, `xs`, `small`, `medium`, `large`, `xl`, `2xl`, and `auto`. Radius values range from `none` to `full`. Size aliases include `full`, `half`, `fit`, `screenH`, `screenW`, and a scale from `0` to `64`.

```tsx
<Card p="large" borderRadius="xl" maxWidth="24" bg="card">
  <YStack gap="small">
    <Text fontWeight="semibold">Token-powered styles</Text>
    <Text color="muted" fontSize="sm">No handwritten CSS needed here.</Text>
  </YStack>
</Card>
```

## Projection tokens

Any size-aligned prop can take a numeric projection token in the form `$n`. It is not a fixed entry in a token table: the number is one tenth of its pixel size at Silva UI's 1000px reference viewport and is converted to a linearly fluid `vw` value.

`$4` is `40px` at a 1000px viewport, `20px` at 500px, and `60px` at 1500px. This lets an intentional ratio such as tab `$8`, button `$4`, and icon or text `$2` remain intact as the viewport changes.

```tsx
<XStack gap="$1.6" p="$2.4">
  <Box w="$8" h="$8" borderRadius="$1.2" bg="card">
    <Text fontSize="$2">Projected scale</Text>
  </Box>
</XStack>
```

Projection tokens currently use the viewport only. They do not establish or inherit container sizing contexts; parent-to-child projection is intentionally reserved for the next sizing phase.

## Interaction conditions

A selected set of properties can be conditionally applied using `hover`, `active` and `focus` values.

```tsx
<Box
  bg={{ default: "card", hover: "teal3" }}
  color={{ default: "primary", hover: "teal12" }}
  p="medium"
  borderRadius="medium"
>
  Hover me
</Box>
```

## Utilities

For custom component wrappers, import `sprinkles`, `splitSprinklesProps`, `toSprinklesClass`, or `cls` from `silva-ui`.
