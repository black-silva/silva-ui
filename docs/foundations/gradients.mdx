# Theme-aware gradients

Use `gradient` on `Box` when the stops should follow the nearest Silva UI theme. It is a compact, typed API for custom gradients, and accepts semantic theme tokens, Radix colour tokens, or valid CSS colour values.

```tsx
import { Box, Text, Theme } from "silva-ui"

<Theme name="midnight">
  <Box
    gradient={{ from: "primary", via: "violet9", to: "cyan9", deg: 135 }}
    borderRadius="large"
    p="large"
  >
    <Text color="primaryContrast">Theme-aware gradient</Text>
  </Box>
</Theme>
```

## Choose the right gradient API

Silva UI has two complementary ways to use gradients:

| Need | Use |
| --- | --- |
| A reusable, fixed visual treatment | Named `backgroundColor` or `color` value such as `aurora` or `ocean` |
| Custom stops that respond to a `Theme` or custom theme | `Box` with the `gradient` prop |

Named gradients and animation are documented in [Visuals](/docs/foundations/visuals). Use `gradient` when a component needs its own colours, direction, or gradient type.

## Gradient options

`from` and `to` are required. `via`, `type`, and `deg` are optional.

| Property | Values | Default |
| --- | --- | --- |
| `from` | theme token or CSS colour | required |
| `to` | theme token or CSS colour | required |
| `via` | theme token or CSS colour | none |
| `type` | `linear`, `radial`, `conic` | `linear` |
| `deg` | degrees for `linear` and `conic` gradients | `90` |

## Theme-aware stops

Token stops compile to Silva UI CSS variables. They respond to the nearest built-in `Theme` and to a custom Vanilla Extract theme using the Silva UI contract. See [Theming](/docs/theming) to create that contract.

```tsx
<Box gradient={{ from: "primary", to: "primaryHover" }} />

<Box gradient={{ from: "violet9", to: "cyan9", deg: 135 }} />
```

Use semantic tokens for gradients with a UI role, such as a primary call to action. Use hue tokens for decorative accents. Literal CSS colours are useful for one-off brand work, but they remain fixed when the theme changes.

### Custom theme example

A gradient inside a custom theme resolves through that wrapper just like `bg`, `color`, and component variants do.

```tsx
import { Box } from "silva-ui"
import { brandTheme } from "./brand-theme.css"

export function BrandBanner() {
  return (
    <section class={brandTheme}>
      <Box
        gradient={{ from: "primary", to: "primaryActive", deg: 135 }}
        borderRadius="large"
        p="large"
      >
        Brand-aware banner
      </Box>
    </section>
  )
}
```

## Gradient types

```tsx
<Box gradient={{ type: "radial", from: "primary", to: "background" }} />

<Box gradient={{ type: "conic", from: "violet9", to: "cyan9", deg: 45 }} />
```

`deg` changes the direction of linear gradients and the start angle of conic gradients. Radial gradients ignore it.

## Reuse the generated CSS

Use `gradientToCss` when a wrapper component or a plain element needs the exact same theme-aware `background-image` value.

```ts
import { gradientToCss } from "silva-ui"

const backgroundImage = gradientToCss({
  from: "primary",
  to: "cyan9",
  deg: 135,
})
```

For CSS capabilities beyond the compact API, use `style` directly:

```tsx
<Box
  style={{
    backgroundImage: "repeating-linear-gradient(45deg, #fff 0 10px, #f1f5f9 10px 20px)",
  }}
/>
```
