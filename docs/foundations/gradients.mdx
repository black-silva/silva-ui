# Theme-aware gradients

Use `gradient` on `Box` when the stops should follow the nearest Silva UI theme. It is a compact, typed API for custom gradients that accepts semantic theme tokens, Radix colour tokens, or valid CSS colour values.

## Use semantic stops for UI meaning

Use semantic stops when a gradient has a UI role: `primary` and `primaryActive` follow the active theme, including a custom theme. Use named hue tokens such as `violet9` and `cyan9` for decorative accents. Literal CSS values are useful for one-off brand work, but remain fixed when the theme changes.

## Choose the right gradient API

| Need | Use |
| --- | --- |
| A reusable, fixed visual treatment | Named `backgroundColor` or `color` value such as `aurora` or `ocean` |
| Custom stops that respond to a `Theme` or custom theme | `Box` with the `gradient` prop |

Named gradients and animation are documented in [Visuals](/docs/foundations/visuals). Use `gradient` when a component needs its own colours, direction, or gradient type.

## Gradient options

`from` and `to` are required. `via`, `type`, and `deg` are optional.

| Property | Values | Default |
| --- | --- | --- |
| `from` | theme token or CSS colour | required |
| `to` | theme token or CSS colour | required |
| `via` | theme token or CSS colour | none |
| `type` | `linear`, `radial`, `conic` | `linear` |
| `deg` | degrees for `linear` and `conic` gradients | `90` |

## Theme scopes update gradient stops

Token stops compile to Silva UI CSS variables. The gradient does not need to be rebuilt when its nearest `Theme` changes: its semantic values resolve in the new scope. The same applies to a custom Vanilla Extract theme that implements the Silva UI contract.

`deg` changes the direction of linear gradients and the start angle of conic gradients. Radial gradients ignore it.

## Reuse the generated CSS

Use `gradientToCss` when a wrapper component or a plain element needs the exact same theme-aware `background-image` value.

```ts
import { gradientToCss } from "silva-ui"

const backgroundImage = gradientToCss({
  from: "primary",
  to: "cyan9",
  deg: 135,
})
```

For CSS capabilities beyond the compact API, use `style` directly:

```tsx
<Box
  style={{
    backgroundImage: "repeating-linear-gradient(45deg, #fff 0 10px, #f1f5f9 10px 20px)",
  }}
/>
```
