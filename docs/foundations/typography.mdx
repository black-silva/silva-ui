# Typography

## Text primitives

`Text` renders a `span` by default and can render common inline or block tags with `as`. `SizableText` adds a coordinated `fontSize` and `lineHeight` size scale: `xs`, `sm`, `md`, `lg` and `xl`.

```tsx

const variant = 0;

<Text color={variant ? 'muted' : undefined}>{variant ? 'Muted supporting text' : 'Token-driven text'}</Text>
```

## Headings

`Heading` uses the appropriate `h1`–`h6` tag based on `level`. Shorthand exports `H1` through `H6` are also available.

<Tabs sync={false}>
  <Tab title="Preview">

<Frame>
  <iframe src="https://black-silva.github.io/silva-ui/previews/?example=api-35-a" title="Rendered headings preview" className="w-full h-80 rounded-xl"></iframe>
</Frame>

  </Tab>
  <Tab title="Code">

```tsx
import { H1, H2, H3, H4, H5, H6, YStack } from "silva-ui"

const variant = 0;

variant ? <YStack gap="small"><H3>Section</H3><H4>Detail</H4><H5>Note</H5><H6>Fine print</H6></YStack> : <YStack gap="small"><H1>Build with confidence</H1><H2>Composable foundations</H2></YStack>
```

  </Tab>
</Tabs>

## Paragraph and Anchor

`Paragraph` is a `SizableText` configured as a paragraph with a default `md` size. `Anchor` renders an accessible, styled link and accepts `href`, `target`, `rel`, and `disabled`.

<Tabs sync={false}>
  <Tab title="Preview">

<Frame>
  <iframe src="https://black-silva.github.io/silva-ui/previews/?example=api-36-a" title="Rendered paragraph preview" className="w-full h-80 rounded-xl"></iframe>
</Frame>

  </Tab>
  <Tab title="Code">

```tsx
import { Paragraph } from "silva-ui"

const variant = 0;

<Paragraph>{variant ? 'Clear prose makes component APIs easier to adopt.' : 'Documentation examples stay close to their implementation.'}</Paragraph>
```

  </Tab>
</Tabs>

Use semantic heading levels in order. Visual sizing can be controlled separately with sprinkles props.
