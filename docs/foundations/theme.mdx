# Theme

Scopes a built-in theme to a subtree.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { Theme, themes, built-in theme exports } from "silva-ui"

<Theme name="midnight" p="lg"><Button>Save changes</Button></Theme>
```

## Another composition

```tsx
import { Theme } from "silva-ui"

<Theme name="emerald"><Text>Scoped themed content</Text></Theme>
```

## Props

| Prop | Type / behaviour |
| --- | --- |
| API-specific props | name: `ThemeName`; ThemeProps: `BaseProps`; built-ins: light, dark, emerald, emeraldDark, midnight |

For the complete public contract, see [Props reference](/docs/reference/props).
