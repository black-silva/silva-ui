# Theme builder

Utilities for defining theme sets from semantic palette values.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { applyThemeTemplate, buildThemeSet, createThemes } from "silva-ui"

const themes = createThemes({ /* palette definitions */ })
```

## Another composition

```tsx
import { applyThemeTemplate } from "silva-ui"

const next = buildThemeSet({ /* template and palette */ })
```

## Props

| Prop | Type / behaviour |
| --- | --- |
| API-specific props | CreateThemesOptions, ThemePalette, ThemeTemplate, ThemeValues, SimpleThemeDefinition, CreatedThemes |

For the complete public contract, see [Props reference](/docs/reference/props).
