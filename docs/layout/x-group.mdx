# XGroup

An inline group that joins adjacent controls visually.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Basic usage

```tsx
import { XGroup } from "silva-ui"

<XGroup><Button>Day</Button><Button>Week</Button><Button>Month</Button></XGroup>
```

## Another composition

```tsx
import { XGroup } from "silva-ui"

<XGroup aria-label="View range">{/* grouped controls */}</XGroup>
```
