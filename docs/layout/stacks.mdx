# Stacks

Flexbox stacks for horizontal and vertical composition.

All components accept [BaseProps](/docs/reference/props#shared-baseprops): sprinkles and projection props, theme colours or gradients, `animation`, `class`, and `children`.

## Another composition

```tsx
import { XStack } from "silva-ui"

<XStack gap="sm" flexWrap="wrap"><Box p="sm">One</Box><Box p="sm">Two</Box></XStack>
```
