# Code of Conduct

## Our standards

We are committed to providing a welcoming, respectful, and inclusive
environment for everyone. Contributors are expected to:

- Be respectful and considerate.
- Welcome constructive feedback.
- Focus on what is best for the project and its users.
- Report problems in good faith.

Unacceptable behavior includes harassment, discrimination, personal attacks,
and publishing private information without permission.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, issues, and
other contributions that violate this code of conduct. Repeated or serious
violations may result in temporary or permanent exclusion from project spaces.

To report a concern, contact the repository maintainers privately through the
contact method listed on the GitHub repository rather than opening a public
issue.
